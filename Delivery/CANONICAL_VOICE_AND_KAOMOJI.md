# Shared evidence presentation and kaomoji boundaries

Prompt1B requires the same human-bridge → clean-evidence presentation for native and degraded answers, ☆ main bullets, and a separate rare, deliberate kaomoji authority. The existing Prompt54 constant incorrectly permitted four kaomojis; the authoritative correction sets an absolute maximum of three, usually zero to one and longer playful answers zero to two.

Both successful validated model selection and retrieval/model-failure evidence now pass through one shared Canonical Voice presentation authority after attribution. A non-medical bridge precedes the supported evidence; the original complete scientific quotations, identifiers, units, qualifiers, numbers, source records and citation eligibility are never rewritten. Fallback main bullets use ☆. The strict evidence validator is unchanged. Semantic metadata is passed to the existing universal renderer; the voice layer does not infer emphasis from keywords.

The separate kaomoji authority contains founder-approved forms, requires explicitly authored emotional intent, caps per-answer counts, avoids recent repetition using memory-only decoration history, and forbids kaomojis for serious/urgent/lab/consent content and Fruit Basket questions/reveals. Rare expressions require explicit matching-moment approval. It does not randomly decorate answers.

This is a PARTIAL implementation: full founder Guide-based long-form voice, emotional-context interpretation and adoption across every feature still require implementation and verification. The new regression tests and modified Ask journey require actual macOS execution; no pending test is marked passed.
