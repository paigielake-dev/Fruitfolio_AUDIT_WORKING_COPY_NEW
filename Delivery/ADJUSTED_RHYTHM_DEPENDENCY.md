# Adjusted Rhythm: implemented safety boundary and remaining dependency

Prompt 1B section 4.9.8 requires optional, evidence-supported educational adjustments, original measurements kept separate, restoration of the original illustration, and an exact insufficient-information explanation when support is inadequate.

The current change adds explicit typical / adjusted / my measurements presentations to the existing view. Typical curves and approved artwork remain the existing engine output. The measurement presentation lists actual stored values, original units and actual dates without interpolating samples. Adjustment is an explicit user selection. With recorded measurements but no approved quantitative calibration, the exact founder-approved insufficient-information title and message are displayed and the original curves remain intact. With no measurements or unreadable storage, the app does not falsely claim a measurement was saved. Restoring the original presentation writes no measurement or prediction data.

This is PARTIAL implementation, not a completed personalization algorithm. The current approved research package does not encode a validated, cited quantitative mapping from the user's specified assay, units, timing and context to an educational curve adjustment. No coefficient, hormone relationship or unmeasured concentration has been invented to fill that gap. Actual supported adjustments and their required applied-disclosure state remain blocked until a defensible approved calibration can be established. Tests for the implemented boundary are added alongside it; actual Xcode/Simulator acceptance is pending.

Actual Run41 screenshot review found that My Measurements still inherited the typical-curve subtitle “general patterns, not measured hormone levels ♡”. That subtitle is now shown only in the educational modes; actual records retain their existing explicit measurement heading and recorded-results disclaimer. The original typical visualization/copy is unchanged. The actual simulator journey now asserts that this contradictory subtitle is absent in My Measurements. This follow-up awaits its own run.
