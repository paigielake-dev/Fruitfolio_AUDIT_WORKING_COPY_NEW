# Readable personal data export and bulk hormone deletion guard

The existing prepare-export action only produced a six-scope metadata summary. It did not create an export file. The page now captures real domain snapshots into readable JSON and opens the system file-export destination. The local record includes the account identity if present, shared pseudonymous username, explicit audio/motion/language preferences, the single authoritative encyclopedia/guide collection with original citation/version snapshots, actual cycle archive and setup, shared reported context, exact hormone results/units/notes, and persisted Fruit Basket progress/question history.

The page explicitly discloses sensitive health information before the action. No automatic sharing, network request, raw defaults dump, credentials, purchase receipts, model binaries or unrelated files are included. JSON bytes remain in memory until the user chooses a system save destination. Cancel never displays the success message. A load error in the known library, context or hormone domain prevents a successful partial export; originals are not modified by export.

This is a readable personal record, not a complete backup: imported image binary contents are explicitly excluded while their saved attachment metadata remains; session-only Ask conversations are not exported. Saved answer text and original reference snapshots are retained. Remote account/sync functionality is not invented. Full exported-image backup, remote account availability, complete deletion coordinators and all-language copy remain separate unfinished requirements.

The remaining native bulk hormone-delete confirmation now uses the canonical watercolor popup, shared blur, explicit scope text, modal focus, cancel/Escape guard and unchanged underlying erase operation. It does not erase cycle records, saved guides, profile or context. Three unit tests verify actual snapshot content, exact numeric/unit/reference preservation, no unrelated secret export or mutation, corrupt-domain failure, and exact document bytes. Two UI tests exercise modal cancellation and the real system export-destination cancellation. Actual Xcode build, tests and native accessibility acceptance are pending.
