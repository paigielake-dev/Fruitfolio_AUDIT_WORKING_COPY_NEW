# Translation layout and multilingual fixtures — awaiting actual execution

The previous candidate adapter joined sentence outputs with single spaces, which discarded source paragraph breaks, line endings, indentation and list/header prefixes. A literal-layout layer now preserves those bytes outside model generation, translates sentence content serially, and reassembles the document in its original structure. Citation placement, exact numeric spelling and medical literal validation are unchanged. Empty sentence-tokenizer results no longer silently yield an empty document.

A new actual Apple-runtime test exercises Spanish, French, German, Portuguese, Italian, Simplified Chinese, Traditional Chinese, Japanese, Korean, Arabic and Hindi against ovulation uncertainty plus the exact 2.5 ng/mL measurement and original source marker. It attaches each actual output/error for semantic review and continues through all targets after a failure. PASS for this fixture would establish runtime execution and the asserted preservation invariants only. It explicitly does not establish general medical meaning, full required-language coverage, production Ask translation, physical-iPhone memory/performance or app-wide localization. No alternate model, cloud service, citation relaxation or changed-number acceptance was introduced.
