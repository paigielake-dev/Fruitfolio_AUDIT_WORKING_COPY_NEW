# Shared native save destination ownership

The existing save destination now owns one visible presentation and one terminal result. The actual SwiftUI callbacks require the visible active scene, actual UIApplication foreground state, no covering coordinated popup, and a matching ephemeral interaction identity. Appearance, disappearance and scene changes rotate that identity without resetting typed book names. Successful acknowledged save and Cancel consume presentation ownership before notifying the parent; persistence failure retains the pending content for recovery/retry. No saved-content schema, source/citation copy, book art, store acknowledgement or duplicate detection is replaced.

Selection validates current book/chapter membership. Creation, style selection, native name binding, save and recovery reload callbacks are guarded. Cancel remains available when storage is protected. The shared storage notice receives an optional interaction guard, passed explicitly here; other callers retain their existing behavior and are not claimed fixed.

Two Apple UI launch vectors (Reduce Motion off/on, accessibility XXXL) are written against the real game root, save sheet and private actual library store. They retain the typed draft over background/resume, explicitly create a book, Cancel with zero saved pages, reopen and save exactly one page, then inspect actual source IDs, source versions, source records, question/answer, original answer ID, knowledge-base version and generation timestamp. The fixture is nonclinical and disposable. Empty-page metadata comparison alone is vacuous; acceptance requires the later actual one-page count.

These UI cases are NOT RUN on Linux. Compiler syntax parsing is not Apple SDK typechecking. Supported Foundation regression suites do not execute this SwiftUI implementation. Genuine queued callback, focus, VoiceOver, keyboard, reduced-motion, storage recovery and device behavior remain Apple verification requirements. User-facing save confirmation acceptance is not inferred solely from sheet dismissal.
