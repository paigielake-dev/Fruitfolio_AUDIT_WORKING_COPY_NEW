# Offline source-excerpt practice in Fruit Basket

Production previously defaulted to an unavailable research adapter, so no actual sourced question could reach the existing game. The existing architecture now uses an actor-backed provider over the same bundled research package and approved-source eligibility gates as Ask/Hormone Library. It searches all ranked eligible note candidates, restores complete original paragraphs, rejects missing/unverified/quarantined source trails, and exhausts available practice IDs before reporting exhaustion. It never uses model memory, web requests, user health records or invented clinical distractor statements.

This is explicitly **source-excerpt practice**, not a validated conceptual medical question bank. A whole source word is blanked once, four distinct vocabulary options are offered, and the original entire paragraph is shown in the explanation with original APA/DOI/URL/version fields. Difficulty bands select different vocabulary; they are **not proof of founder-required scientific question-depth quality**. Reviewed conceptual questions, sufficient topic coverage and educational/content acceptance remain open. Unsupported topics mean no eligible excerpt in this mode, not proof that all external research has been acquired. Full-source expansion and quarantined research reconciliation remain blockers in BLOCKERS.md.

The catch rule is a visual starred/unstarred classification, explicitly not a nutrition/clinical claim about those fruit. Standalone stars remain independent bonuses. Existing answer → catch → Basket Reveal order, round consequence policy and saved-library architecture remain. Explanations encode literal source text through canonical semantic markup, preserving operators/underscores/quantities; source records pass through feedback, reveal and saved-page metadata. Original citations are never translated. Exact cloze questions/answers retain original wording; jointly validated localized question/answer generation remains open and official MADLAD weights/inference are still blocked. Independently translating answer choices could invalidate this exact-quote exercise and is not represented as verified localization.

Revised founder menu/instruction/topic wording and explicit good/bad/star/pass guidance are applied. The game tour uses the canonical measured taped-white popup and shared background blur/accessibility exclusion. Its inline instruction cards remain ordinary cards. Explicit question operations are owned by the view; generation/topic/difficulty/screen guards reject delayed results and errors after navigation, cancellation or replacement, before any question-history write. Two real view-model suspension regressions await Apple/Combine runtime.

Urgent phrase matches retain the existing safety response before package loading. Sensitive educational topics remain eligible and use serious sourced feedback: playful characters/emoticons/celebratory feedback are suppressed rather than excluding those topics from the library. Source paragraphs containing serious material also require that tone; sensitivity alone never bypasses retrieval. Word boundaries fix the existing false positive that matched `rape` inside `grapes`, while whitespace and curly-apostrophe variants preserve actual urgent matches. This remains a conservative English phrase router, not multilingual emergency diagnosis or exhaustive detection.

Verification includes actual bundled-corpus questions for all three vocabulary levels, full paragraph restoration, exact citation fields, fixture exhaustion, all eligibility gates, package-independent safety routing, scientific literal preservation and Codable source-record round trips. Apple UI typechecking, tour fit/VoiceOver, gameplay launch and physical performance remain NOT RUN on Linux. No runtime playability or clinical review is claimed solely from these source changes.
