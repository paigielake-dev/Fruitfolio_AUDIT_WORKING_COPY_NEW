# Saved-page fixed copy and notice provenance

The actual saved-page view now routes its fixed heading, note/image labels, authored-material qualifier, note accessibility label and image picker actions through the existing control translation owner. The heading has separate layout space from the original Back artwork, wraps vertically and retains the original font size. Ten missing English source fallbacks were added; all thirteen typed library-error source messages already had English fallback entries. This does not certify translations for supported languages.

`Prompt10SavedPageNotice` establishes provenance from known operations or a typed `Prompt10LibraryError`. Only those sources can enter translation. A foreign `LocalizedError` remains `.external` even when its text exactly matches a known notice. The view renders external text verbatim, avoiding both inference and semantic Markdown interpretation. The notes-save success marker is cleared only for that typed operation when a new draft is entered. Generic image failure text retains its existing privacy-preserving wording.

The user note binding and its implicit native value remain unchanged. Saved question text is explicitly verbatim; body translation, original body bytes, citations, scientific numbers, selected excerpt language and canonical persistence are unchanged. Successful note edits do not authorize legacy excerpt deletion. No notice is added to persisted records.

Two Foundation tests cover all known operation/error variants and spoofed/untrusted Unicode/Markdown-looking external messages. Four Apple UI vectors were written for English/Arabic, paused inference, Reduce Motion and accessibility XXXL: heading/Back separation, actual notes save, exact authored draft retention, typed success visibility, and clearing stale success on the next unsaved edit. Apple vectors are NOT_RUN on Linux. Full Linux results, source parsing and control-sound source ownership appear separately in the run log; none proves Apple SDK compatibility, VoiceOver/focus, official MADLAD inference, language quality or clinical safety.
