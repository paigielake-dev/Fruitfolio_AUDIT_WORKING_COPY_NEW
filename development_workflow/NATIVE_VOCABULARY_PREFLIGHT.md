# Native vocabulary preflight before tensor loading

A declared language now passes actual native tokenizer/tag validation using a scoped llama vocabulary-only model before the full tensor model is loaded. The scoped model is freed on success, cancellation or error. Existing full-model tag validation remains as a second check. Full tensor-model/context/encode/decode counters keep their original scope; separate counters sample vocabulary preflight calls, invoking main thread and active scoped handles. These are ownership/thread observations, not resident-memory profiling.

Actual negative vocabulary evidence is cached for the current resource epoch (at most512tags). A verified manifest/checksum/header descriptor is also reused within that epoch so switching from an unsupported tag to another tag does not repeatedly hash the same immutable weights. Both caches clear on explicit resource release, matching the existing loaded-model lifecycle. Resource replacement requires release/reload. The cache contains resource metadata and tags only, never source text or translation results.

Two baseline native cases reproduced four failed assertions: declared-but-absent tags loaded the tensor model, and a tensor-free vocabulary fixture could not reject at the tokenizer stage. The revised focused cases pass with the real native CPU C API, including a synthetic GGUF with zero tensors. A second new case checks repeated rejection, zero retained scoped handles, off-main preflight and cache invalidation after resource release. The existing declared-tag test also verifies one checksum/header verification per epoch before a supported synthetic tag proceeds to its untrained graph.

All these GGUF fixtures are explicitly synthetic and untrained, NOT official MADLAD. A vocabulary token is necessary, not sufficient for working translation or linguistic/clinical quality. No official weights/tokenizer are available in this environment; no official inference, device peak RAM or latency improvement is claimed. Actual model/tokenizer, cold/warm memory/thermal/latency, Apple framework/device and native-language/clinical review remain open.
