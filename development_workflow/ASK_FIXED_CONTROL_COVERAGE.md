Four new Apple UI vectors type an original ASCII question, open/scroll/close actual Help, verify input identity and heading bounds, and capture the returning screen at XXXL size. They are NOT_RUN. This is a synthetic layout fixture, not grounded clinical output or learned translation. Existing normal Ask QA flags keep their previous settings. Five additional English fallback catalog keys were added; no foreign translations were invented.

Linux Foundation/actual native CPU suites and syntax/workflow/source-ownership checks do not typecheck SwiftUI or execute these UI paths.
