# Shared username instructions and localized counters

Account and Fruit Basket retain the existing shared username store and persistence schema. Their independent labels now use a shared fixed-accessibility-hint modifier for the same policy instructions. The modifier owns compact translation, preserves explicit fallback/provenance, respects memory-pressure pause, cancels obsolete tasks through the existing translation owner and never replaces the field label or translates the authored username.

Fruit Basket also routes the public-name label and privacy field exclusion notice through fixed-copy translation. Its username-length range protects native numerals; the live length fraction uses the existing native number formatter. One English source-key fallback is added without changing older catalog objects. Typed draft/saved strings remain verbatim.

One new Apple UI method defines four launch vectors: English and Arabic with inference paused, each with Reduce Motion on/off at accessibility XXXL. It checks native count, unchanged authored draft and actual saved-store readback after confirmation. It has NOT RUN on Linux and does not establish translated Arabic text, VoiceOver hint speech or native Apple typechecking. Existing authority/write-acknowledgement regression suites remain distinct evidence; source presence does not establish whole-requirement completion.

Real/legal-name exclusion still uses explicit non-identifying confirmation and available identifying text; it cannot certify identity from an arbitrary pseudonym. Public/global registration remains unconfigured. Official MADLAD inference and human scientific/native-language review remain blocked separately.
