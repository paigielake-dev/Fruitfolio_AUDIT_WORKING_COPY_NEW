# Guide headers, cards and metadata provenance

The existing Guide home header, empty messages, new-guide controls, workspace options and numeric summaries now use the control translation owner. The original heart/kaomoji and feature label are protected. One missing English fallback was added. Original artwork, source text and canonical Library/Guide structure remain intact.

`Prompt11GuideCountCopy` formats native count glyphs for the selected language and exposes the exact literals to protect in translation. `Prompt11GuideTileCopy` escapes and protects authored names independently of numeric prose. Visual names/subtitles remain verbatim. Workspace titles and card names/subtitles wrap at their original font sizes instead of shrinking or truncating at two lines. The workspace places navigation controls above the authored title, keeping each its own layout space.

The options action omits its layout animation when Reduce Motion is active and retains the original normal animation. Reorder error rendering reuses the canonical typed Library notice renderer: known domain errors can translate, external errors stay verbatim, and existing storage notices retain priority. No new persistence or rewrite of guide body/citation data is introduced.

Two Foundation regressions test numeric integrity across five locales (zero, singular and plural) and exact authored-name protection through the scientific translation envelope. A third real canonical-store test covers the explicit DEBUG long-title private fixture and non-mutating remount. The initial focused six-test run precedes that third case; the full suites include it. Four Apple UI vectors were written for the actual private long-title Guide at English/Arabic, paused inference, Reduce Motion and accessibility XXXL. They cover exact title text, independent navigation frames, native count fallback and options toggling.

Apple vectors are NOT_RUN. Changed Swift source parsing, Linux envelope/store tests and source sound ownership do not establish SwiftUI SDK typechecking, VoiceOver, actual translated layout, animation behavior on a device, official MADLAD inference, linguistic quality or clinical safety. Existing small baseline card fonts are preserved; device readability remains unverified. This is bounded header/card/metadata coverage, not certification of every Guide control or checklist requirement.
