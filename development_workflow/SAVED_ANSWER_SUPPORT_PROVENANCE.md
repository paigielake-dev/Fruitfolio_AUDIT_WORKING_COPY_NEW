# Saved answer support provenance and selection privacy

An optional typed metadata snapshot now preserves the exposed Ask response classification, concept support map, answer path, preview qualification and capture scope. Original body, citations, version map and timestamps remain separate. No research packet, ephemeral user-context object or missing claim/evidence relationship is copied or invented. This preserves the exposed response support map, not an otherwise absent full per-claim evidence graph.

All four Ask save paths populate the snapshot. Pending selections and saved-page constructors restrict excerpts/image-only selections to original-response status/path/preview and omit unsaved concept text. A supported full response is not treated as an independently assessed selection. The actual save destination and guide-reference bridge carry metadata; existing page-note updates preserve it. Older pages without the optional field retain unknown status. Unknown future fields/enum values and explicit null data stay protected against rewriting by the existing persistence boundary. No storage key or destructive migration is introduced.

Current/historical Ask and app-generated encyclopedia/guide/source reading display serious qualification notices when relevant. Preview, unavailable, safety, partial and unsupported states stay distinct; notices for selections identify the original full-response scope. Authored pages/notes are not presented as research-qualified content. Eight English fallback notice keys were added; no foreign translations or clinical classifications were invented. Translated notice meaning still requires actual-model and native-language review.
