# Library sort translation and interaction ownership

The existing Library sort binding and ordering modes are unchanged. Trigger/options now use the canonical translated watercolor control, preserving selected traits and one source-owned soft-pop request per action. Expanded/collapsed value uses a shared fixed accessibility value owner that retains explicit provenance inside the value; it does not overwrite the independently owned label or hint. Four English trigger fallback keys are added without changing older catalog objects.

The actual widget uses a small Foundation interaction gate. Only a visible active menu can toggle; only its current expanded ticket can return a selection, which consumes that ticket. Scene/disappearance/parent modal or book-opening transitions deactivate it. The actual callback also checks the live parent authorization closure and current UIApplication activity. Queued focus restoration requires the same closed ticket and live root authorization, so reopen/hide cannot restore old focus. Reduce Motion disables explicit menu animation. None of this writes books or changes the selected-language authority.

Four Foundation cases exercise invalid collapsed/inactive selection, duplicate toggle/selection, stale selection after reopening/reactivation and expiring closed/focus tickets. They verify the same gate integrated in the widget, not actual VoiceOver or UIKit scheduling. Existing four Library UI vectors now check selected option traits, changed trigger/state, reopen/close and exactly one software pop request per action. All four remain NOT_RUN. Actual keyboard/VoiceOver/focus/selected styling/RTL/XXXL, background/modal timing and audible playback require Apple/device execution.

The source ownership scan is not AVFoundation playback proof. Generic translation ownership tests and synthetic native T5 tests are not official MADLAD inference or reviewed native-language quality. Whole original389/390/397 remain open pending integrated acceptance.
